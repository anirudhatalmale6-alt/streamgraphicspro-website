StreamGraphics Pro — website (plain static files, no subscription, no build step)
================================================================================
Pages: index.html (home), pricing.html, tutorials.html, faq.html, docs.html (manual), site.css

TO PUBLISH ON SITEGROUND:
1. Log in to SiteGround → Site Tools → File Manager.
2. Open your site's web root (usually "public_html").
3. Upload ALL files in this folder (index.html, the other .html files, site.css) into it.
   - For the marketing site at streamgraphicspro.com, put them in public_html.
   - For docs at docs.streamgraphicspro.com, create that subdomain and upload docs.html + site.css there.
4. Visit your domain — done. Edit any .html in a text editor to change wording; edit site.css for colours.

TO EDIT:
- Prices: pricing.html (search for "$199" / "$0" / "$—").
- Add your video: tutorials.html (replace the placeholder box with a YouTube/Vimeo <iframe>).
- Download links: pricing.html (the two Download buttons) — point them at your installer once packaged.
- Contact/support: faq.html (last question).
