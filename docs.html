StreamGraphics Pro — Manual

Everything you need to build and run your graphics.

Getting started

StreamGraphics Pro runs on your own computer. Launch it and it opens a home screen (the "All graphics" menu) listing each graphic: Presenter's Timer, Beach Volleyball Scoreboard, Lower Third / Graphics Builder, and the Show Library.

Each graphic has two parts: a control page (you drive it from here, in any browser on your network) and an output page (the transparent view you put on your stream). Open a control, and keep the output for OBS/vMix.

Adding the output to OBS / vMix

Every graphic shows its Output URL. Copy it, then:

  • OBS: add a Browser Source, paste the URL, set size to 1920 × 1080.
  • vMix: add a Web Browser input, paste the URL, set 1920 × 1080.

The output is transparent, so your graphic sits over your video with no background. Need a solid colour for a hardware keyer instead? Use the Chroma key option and pick a colour that isn't in your graphic.

Tip: on the first load, give the browser source a few seconds to warm up before going live.

Graphics builder

The builder is a free-form 1920×1080 canvas. Add layers from the buttons: Text, Box, Image, Video, Ticker, Timer, Slides, BG. Click a layer to select it; drag to move; use the handles to resize and rotate; press Delete to remove it. Arrow keys nudge 1px (Shift = 10px), and the Align buttons line things up.

The Layers panel lists everything top-to-bottom. Click a row to select, double-click its name to rename, use 👁 to show/hide and 🔒 to lock. Shift/Ctrl-click several rows and hit Group to move and animate them together. On the canvas, Alt-click to reach a layer hidden beneath another.

When a design is ready, Take to air to preview on the output, or Save to Library to keep it as a preset. New starts a blank design.

Animations

Every layer has its own Animate ON and Animate OFF — type, delay and duration — so you can stagger reveals. Choose from fade, slides, fly-in from off-screen, bounce, pop and spin. Hit Preview animation to see it right in the builder.

Inside a group, set a layer's animation to None and it follows the group's animation — so a background box flies in with the group instead of just popping on.

Timers & clocks

There's a standalone Presenter's Timer (with warning colours and overtime for speakers), and a Timer layer you can drop into any design. Modes: countdown, count-up, countdown-to-a-time, and a live clock. The clock is anchored to the app, so multiple machines stay perfectly in sync.

Slides

Add a Slides layer, type your blocks of text (one blank line between slides), then advance with First / Prev / Next / Blank — like lyrics or scripture. Use // or a new line for a line break, and start a line with - for a bullet. Give slides an optional background panel that stays put while the text changes.

Scoreboard & the big-button Scorer

The Scoreboard control sets team names, seeds, colours, logos and per-game scores. Take it to air like any graphic. For live scoring, open the Scorer — a clean, big-button screen (great on a tablet) that just keeps score; it can't accidentally take the board off air (only the director does that from the full control).

Multiple courts

Run several independent scoreboards from one app. On the Scoreboard control, use ＋ New board to add a court, and the dropdown to switch between them. Each board has its own output and scorer link — so five courts is five browser-source URLs, one app, one computer.

Show Library & Program output

The Show Library holds your saved graphics. Flip any of them on or off and they appear together on the single Program output — add that one URL to OBS/vMix and switch graphics live from the Library. Each preset can be Edited (back into the builder), renamed or deleted.

CSV mail-merge

Mark a text or image layer as a CSV field in the builder (e.g. name it PlayerName). Save it to the Library, then Import CSV on that graphic — the column headers match your field names, and each row becomes a ready-to-go version. Step through with ◀ ▶ or jump to anyone by name. No spreadsheet? Use Manual Add to type entries by hand. There's a per-graphic option to animate the change and a delay to make it smooth.

Images & media

Driving images from a CSV? Drop your photos into the Library's image panel — no folder access needed — and organise them into folders per show/event. Your spreadsheet only needs the file name (even a full path from your computer works); the app finds the image by name in any folder.

Templates

In the builder, hit ▤ Templates to start from a ready-made design — clean lower thirds, title cards, a countdown, a ticker, a sponsor bar and more. Customise it and Save to Library. You can also Save current as Template, and Export / Import templates as files to share or sell as packs.

Licensing

The free version shows a small watermark on the output. On the home screen, open the License card, paste your key and click Activate — the watermark disappears and any add-ons unlock. Licenses work offline, so no internet is needed at the venue.

Tips & troubleshooting

I updated but don't see the new feature. Download the latest version and restart the app — refreshing the browser alone won't add new features.

My animation isn't playing on air. Animations play on the output when a graphic goes on/off air. Use Preview animation in the builder to check it instantly.

A CSV image isn't showing. Make sure the image is uploaded in the Library's image panel and the image layer has a matching CSV field name.

The first load in OBS/vMix lags. That's the browser source warming up — let it sit a few seconds before going live; it's instant after that.
