StreamGraphics Pro — User Guide

A friendly, thorough walk-through of every part of the app. Skim the sidebar for what you need, or read start to finish.

Install & launch

StreamGraphics Pro runs on your own computer — Windows or Mac. Download it from the pricing page, install, and launch it like any program. When it starts, it opens the home screen (the "All graphics" menu) in your browser. Leave the app running for the whole show; closing it takes your graphics offline.

Putting it on the taskbar. Right-click the Start Menu entry or the desktop icon and choose Pin to taskbar. From then on the app is one click away, with its own icon.

The home screen

The home screen lists your graphics, the Control API, and your license status:

  • Presenter's Timer — a standalone countdown/clock for speakers.
  • Scoreboards — beach volleyball and baseball/softball (each with its output and, for volleyball, the big-button Scorer).
  • Lower Third / Graphics Builder — design any graphic you like.
  • Show Library — save graphics and run them together.
  • Control API — command URLs for a Stream Deck, Bitfocus Companion or any automation.

Each entry has an Open control link (the panel you drive it from) and an Output link (the transparent view you put on the stream).

How it works — control vs output

Every graphic has two halves:

  • A control page — this is your dashboard. You open it in a browser and use it to build, edit and trigger the graphic. Nothing on the control page ever appears on your stream.
  • An output page — a transparent 1920×1080 view of just the graphic. This is what you add to OBS or vMix.

They stay in sync in real time: whatever you do on the control instantly updates the output. You can have the output open in OBS while you drive from a laptop, tablet or phone.

Using it from other devices (phones, tablets, laptops)

Because it runs a little web server, any device on the same network can open the control pages — great for handing a scorer a tablet while you run graphics from a laptop. On the show computer, the app's home page has a box called Use on another device (same network) showing that computer's own address. Type that address into the other device's browser to reach the same controls. Everyone's changes sync live.

Multiple operators: there's no limit — a scorer, a director and a graphics operator can all work at once without stepping on each other (last change wins).

Adding a graphic to OBS

  1. On the graphic's control page, copy the Output URL (there's a Copy button).
  2. In OBS, click + under Sources → Browser → name it → OK.
  3. Paste the URL into URL. Set Width 1920, Height 1080.
  4. OK. Your graphic now floats over your scene with a transparent background.

Audio from a video layer: tick "Control audio via OBS" on the Browser Source if you want a video's sound on the stream.

Adding a graphic to vMix

  1. Copy the Output URL from the control page.
  2. In vMix: Add Input → Web Browser → paste the URL → set 1920 × 1080 → OK.
  3. Use it as an overlay channel over your program.

Transparency & chroma key

The output is transparent by default, so it composites cleanly in OBS/vMix — no keying needed. If you're feeding a hardware switcher (which needs solid video), use the Chroma key selector on the builder: pick Green, Blue, Magenta, White, Black, Red, or a Custom colour that doesn't appear in your graphic, and key that colour in your switcher. Full-screen graphics don't need a key at all.

Graphics builder — the canvas & selecting

The builder is a free-form 1920×1080 canvas shown scaled down. The dashed rectangle is the title-safe area — keep important text inside it. Add layers with the buttons across the top of the side panel: Text, Box, Image, Video, Ticker, Timer, Slides, BG.

Moving, resizing, rotating

  • Select: click a layer on the canvas (or click its row in the Layers list).
  • Move: drag it. Or use the arrow keys to nudge 1px (Shift+arrow moves 10px).
  • Resize: drag the square handles.
  • Rotate: drag the round handle above the layer.
  • Delete: press Delete (when you're not typing in a field).
  • Reach a hidden layer: Alt-click the same spot to dig to the layer beneath.

Reference image

Under the canvas you can load a reference image (a screenshot of the look you're matching) at an adjustable opacity. It's a design aid only — it never appears on air.

Saving your work

Take to air previews the design on the output. Save to Library stores it as a reusable preset. New clears the canvas for a fresh design. Templates starts you from a ready-made look.

The Layers panel

Everything you add is listed here, top layer first. For each layer:

  • Select by clicking the row; rename by double-clicking its name.
  • 👁 Show/hide — hide a layer without deleting it.
  • 🔒 Lock — make it un-clickable on the canvas so you don't move it by accident (still visible on air).
  • ▲ ▼ — move it up or down the stack.

Grouping

Shift- or Ctrl-click several rows to select them, then Group. Grouped layers move together, and can animate together (see Animations). Ungroup separates them again.

Text layer

Add a Text layer and type in the Text box. Options: Font, Size, Bold, Colour, and Align (left/center/right). Use the CSV field box to make this text fillable from a spreadsheet (see CSV mail-merge) — e.g. name it PlayerName.

Box & BG layers

A Box is a coloured rectangle — perfect as a backing bar behind text. Options: Fill colour, Opacity (for a translucent panel), and Radius (rounded corners). A BG is simply a full-screen box for a solid background.

Image layer

Add an image by pasting a URL or clicking Browse to upload one. Options: Shape (none / rounded / circle — great for headshots) and Fit (contain shows the whole image; cover fills the frame). Set a CSV field to drive different images per row from a spreadsheet.

Video layer

Add a video by URL or Browse. Options: Autoplay on air, Loop, Muted, Fit, and When it ends (Hold last frame, or Hide). There are Play / Pause / Restart controls too. Notes: browsers require videos to start muted to autoplay; for a transparent clip use a WebM (VP9) with alpha. Very large files can be slow — keep clips reasonably sized.

Ticker layer

A scrolling headline bar. Type your text (use the ⤢ pop-out for long text), and set Speed, Direction, text colour/size/bold, and the bar's Fill, Opacity and Radius.

Timer layer

Drop a live timer into any design. Choose the Type: Countdown, Count up, Countdown to a time, or Clock (time of day). Set the duration and press Start / Pause / Reset. Extra options: Show hours, Overtime (a countdown keeps going negative in red), and 24-hour for the clock. Style it like text (colour, size, bold, font, align). The clock is anchored to the app, so multiple machines match to the second.

Slides layer

For lyrics, scripture or bullet lists. Type your slides in the box — one blank line between slides. Within a slide, press Enter or type // for a line break, and start a line with - for a bullet. Advance with First / Prev / Next / Blank, or jump using the counter. Options: an optional background panel (colour, opacity, padding, radius) that stays put while the text changes, and a Between slides transition (fade or slide).

Bullets layer (builds)

Reveal talking points one at a time, the way a presenter builds a PowerPoint slide — except live, on your stream, driven from a button. Add one with ＋ Bullets and type your points, one per line. Blank lines are ignored.

The four reveal styles

All four use the same list; the Reveal style dropdown only changes how a point that isn't the current one is drawn:

  • Build — each new point appears beneath the last and everything stays at full strength. The classic PowerPoint build.
  • Fade — earlier points stay on screen but dim back, so the eye lands on the newest one. This is the look you see when commentators are talking over a graphic.
  • Highlight — every point is on screen from the start, all dimmed, and the one being discussed lights up. Good for an agenda or a running order.
  • Replace — one point at a time in the same spot, each replacing the last.

Because it's one layer and not four, you can switch style mid-show on a graphic you already built.

Driving it

In the builder, use First / Prev / Next / All / Blank. Once the graphic is saved to the Show Library, every preset that contains a bullet list grows a Reveal row with the same transport — that's what you use on air. The same commands are on the Control API and in the Companion module, so Next point can be a physical key. See Stream Deck & Companion.

Options worth knowing

  • Grow upward instead of downward — a build sitting above a lower third should push up, not down into it.
  • Arrives sets how each point comes in (fade, slide, pop) and how long it takes. ▶ Test replays the whole build in the preview.
  • Marker: dot, dash, arrow, tick, numbers, or none — with its own colour.
  • Dimmed at controls how far back Fade and Highlight push the other points; Highlight also has its own colour and an optional size bump for the live point.
  • Start from blank each time it goes on air (on by default). Without it, a graphic saved with everything showing comes back on air fully revealed and you'd have to blank it before every show. Turn it off if you want a static list.
  • CSV field — a bullets layer can take its whole list from one spreadsheet cell. Separate the points with // inside the cell, and a "Talking points" column gives every guest their own build. See CSV mail-merge.

Animations

Every layer has an independent Animate ON (how it comes on) and Animate OFF (how it leaves), each with its own type, delay and duration. Types include Fade, Slide (up/down/left/right), Fly-in from off-screen, Bounce, Pop and Spin.

Staggering

Because each layer has its own delay, you can stage a reveal — e.g. slide the background bar on, then bring the name in 200ms later, then the title 100ms after that.

Group animations

Inside a group, set a layer's animation to None and it inherits the group's animation — so a plain background box flies in with the group as one unit instead of just popping on.

Preview

Click Preview animation to play the IN then OUT right on the builder canvas, so you can fine-tune without taking it to air. On the stream, animations play when the graphic goes on and off air.

Align & nudge

Select one or more layers and use the Align buttons — Left, Center, Right, Top, Middle, Bottom. With one layer selected it aligns to the whole frame; with several selected it aligns them to each other. Arrow keys nudge the selection 1px (10px with Shift).

Scoreboard — setting up a match

Open the Scoreboard control. For each team, set Player 1 / Player 2 names and a Seed, or pick a saved team from the team library dropdown. Set the event Title, Presenter and Bracket label at the top.

Scoring & games

  • + / − under each game column changes that team's score.
  • Restart Match — sets game 1 to 0 and the rest to "--".
  • Start Next Game — brings the next "--" game to 0 and makes it the active (highlighted) game.
  • Back a Game — undoes Start Next Game if it was pressed by mistake.

Look, event logo & backdrop

Set each team's Bar, Row and Text colours and a team Logo. For the event logo, choose inline (inside the board) or place it as a free overlay in any corner — when it sits beside the board, the board shifts over so the logo isn't hidden. You can also drop in a Photoshop backdrop image to replace the coded frame entirely, set the position and animation, and a chroma colour for hardware keying.

The big-button Scorer

Open the Scorer (linked from the scoreboard, and great on a tablet). It's a clean screen with a huge team-coloured +1 button per side, big live scores, a small Undo point, game tabs, and Start Next Game / Back / Restart. A scorer can run the whole match without touching the detailed panel — and importantly, the Scorer cannot take the board on or off air, so it can never disappear on your director by accident.

Multiple courts

Run several independent scoreboards from one app. On the Scoreboard control, use ＋ New board to add a court and the dropdown to switch between them; Rename and Delete are there too. Each board has its own output link and its own Scorer link, so five courts is five browser-source URLs from one computer — no extra IP addresses, no port juggling.

Show Library & Program output

The Show Library is your collection of saved graphics. Each has an on/off switch — flip several on and they appear together on the single Program output. Add that one URL to OBS/vMix and run your whole show from the Library, switching graphics live. Other buttons: Edit Preset (opens it back in the builder), Rename, Delete, and All off to clear the screen fast. Each graphic plays its own designed animations as it comes on and off.

A graphic containing bullets or slides also gets a Reveal row — First / Prev / Next / All / Blank — so you can step a build while it's on air without going back to the builder. If one graphic holds more than one list, pick which one the buttons drive from the dropdown.

CSV mail-merge (fill graphics from a spreadsheet)

Turn one graphic into many by feeding it a spreadsheet.

  1. In the builder, give a text (or image) layer a CSV field name — e.g. PlayerName, Position, Photo. Save the graphic to the Library.
  2. On that graphic in the Library, click Import CSV. Your column headers match the field names.
  3. Each row becomes a ready-to-go version. Step through with ◀ ▶, jump to anyone from the dropdown, and choose which column is the label with Row by.

A bullets layer can take a CSV field too — put the whole list in one cell, separated by //, and each row brings its own set of talking points.

Smooth changes

Tick animate change so the graphic animates out and back in between entries, and set a delay (ms) so it isn't jarring — snappy for a roster, slower for a graceful feature reveal.

Fixing the spreadsheet mid-show

Rosters are wrong. A name runs off the end of the lower third, somebody scratches an hour before warm-ups, a late entry turns up at the table. You should not have to go back to Excel, re-export and re-import while the event is running — so you don't.

Click ✎ Edit rows on any graphic that has a spreadsheet attached. You get the whole sheet as a table:

  • Change any text — shorten a name that doesn't fit, fix a spelling, correct a position.
  • Delete an entry, add one, or reorder with ▲ ▼ to match the running order.
  • ▶ on any row puts that entry straight on air.
  • ＋ Add field if the spreadsheet arrived missing a column your design needs.

There is no Save button, deliberately — every change is saved the moment you make it, so there is nothing to forget under pressure. The entry that's currently on air is highlighted in red, and if you edit that one the Program output updates as you type.

Adding or deleting a row never disturbs what's on air: the app follows the entry, not the row number. If you delete the wrong one, Undo puts it back where it was. Cells longer than about 26 characters get an amber edge as a hint that they may not fit. With a long roster, use the Filter box to find one person among hundreds, and On-air row to jump back to whoever is up.

Templates & template packs

Hit ▤ Templates in the builder to see every design you can start from, each drawn as a real preview rather than a name in a list — what you see on the card is what lands on your canvas. Click a preview to load it, then customise it and save it to your Library.

The built-ins cover clean lower thirds in several colours, full-screen title, colour and photo backgrounds, a countdown card, a news ticker, "coming up next", a sponsor bar and a LIVE bug. ＋ Save current design adds whatever is on your canvas to the list.

Use the chips along the top to move between Built-in, My designs and any pack you've installed, or type in the search box to find one by name.

Installing a pack

A template pack is a single .sgpack file holding a set of designs — a sport, a look, a whole season's branding. Click ⤒ Install pack and choose the file. The designs appear immediately under their own chip, and any images they use travel inside the file, so a pack works on a computer that has never seen those photos.

Packs stay separate from your own work. Uninstall this pack removes the pack and its designs in one go — anything you already saved to your Library stays exactly where it is.

Making a pack of your own

Building one is the same screen. Tick the box on each design you want, click ✦ Make a pack…, then give it a name, an author, a version and a short description. You get a .sgpack file you can back up, hand to a colleague, or sell.

Two things worth knowing. Images are embedded in the file, so check you have the right to distribute any logo or photo you include. And the version field is there so you can ship Pack 1.1 later — installing a newer one doesn't disturb the copy already on someone's machine, so tell people to uninstall the old version first if you mean it as a replacement.

Manual entries (no spreadsheet)

No CSV? Click Manual Add on a graphic to get a little form of its fields — type an entry and add it. Add as many as you like; they behave exactly like imported rows.

Images & media folders

Driving images from a CSV? Open the Library's image panel and drop your photos in — no folder access needed. Organise them into folders per show or event (create a folder, upload into it, rename or delete images and folders). Your spreadsheet only needs the file name — even a full path from your computer works — and the app finds the image by name in any folder. Tip: keep file names unique across folders so there's no confusion.

Back up & share graphics (Export / Import / Archive)

First, the simple case: everyone on one show computer already shares everything. Because the app runs one little server, every operator, tablet and laptop on your network sees the same presets, library and media live — there's nothing to sync. Save a graphic on the show computer and the whole room has it instantly.

To move graphics between different computers (a second install at another venue, a backup, or handing a design to a colleague), use Export / Import in the Show Library:

  • Export all — downloads your whole library as one .sglib file. That single file is your backup/archive, and it's how you copy your graphics to another install.
  • Export (on a single preset) — saves just that graphic as a .sgpreset file to share.
  • Import — loads a .sglib or .sgpreset file. It merges in (it never overwrites what you already have), so you can safely combine libraries.

Images travel with the graphic. When you export, any logos and photos a graphic uses are bundled right into the file, so it looks identical on the other computer with nothing else to copy. (Very large images and video clips are kept as links to keep the file a sensible size.) Templates can also be exported/imported one at a time from the Graphics Builder.

Control API — Stream Deck & Bitfocus Companion

StreamGraphics can be driven from a Stream Deck, Bitfocus Companion, or any automation — one web address per button. Everything is addressed by the name you gave it in the app, so a button keeps working no matter how you rearrange your show.

Open Control API from the home screen (or go to /control-api). It lists every command with a ready-to-paste URL, a Copy and a Test button, and a box where you set the show computer's network address so the URLs are ready to use from another machine. It even shows your live preset and scoreboard names.

Bitfocus Companion — use the module

There is a native StreamGraphics Pro module for Companion, and it is by far the easier route. It's free — including with the free version of the app. Download it and see the install steps here.

Add it as a connection, put in the show computer's address and port 4000, and you're done.

Then open Companion's Presets tab and drag buttons out — don't build them by hand. The module reads your actual show and generates buttons that are already wired up: a toggle for every saved graphic, a full scoring set for every scoreboard you've made, plus the presenter timer and the baseball board. Run five courts and you get five ready-made scoring pages.

What the module gives you that plain URLs can't:

  • Button colours that mean something — a graphic's button turns red while it's actually on the Program output, not just when you last pressed it. Same for scoreboards and the timer.
  • Live numbers on the keys — the real score, the team names, which spreadsheet row is showing, the presenter clock ticking down, the baseball count.
  • A connection light — park it on a spare key and you'll know the link is healthy before the first serve, not during it.
  • It follows your show — rename a court or add one and the buttons and variables update on their own.

Without the module — one URL per button

Any Stream Deck, automation tool or Companion install without the module can still drive everything with plain web addresses. In Companion, add an action of Generic HTTP Request, set the method to GET, and paste a URL from the Control API page. Press the button — the graphic reacts instantly.

Stream Deck: tick "Access in background", or you'll collect browser tabs

The Stream Deck app's built-in Website action opens a browser tab on every press, so an hour of shows leaves you with a row of tabs showing {"ok":true}. In that action's settings, tick Access in background (older versions say "Open in background"). The key then sends the command silently with no browser involved. The graphic was reacting correctly all along — the tabs are just the Stream Deck showing you the reply.

What you can control

  • Library presets by name — on / off / toggle, and next / previous row for CSV graphics.
  • Bullet builds — next / previous point, reveal all, back to blank, or jump straight to point 3. See Bullets. The module ships ready-made Next / Back / All / Blank keys for every graphic that builds, with the count printed on the key.
  • Presenter timer — start / pause / reset / set (e.g. 5:00) / add time / on-air / off.
  • A named scoreboard — point +/− per team, next game, show / hide.
  • Baseball / softball — run per team, ball / strike / out, clear count, next half-inning, on / off.

The module and the URLs cover the same ground, so nothing is off-limits either way.

Example — a Stream Deck button becomes literally one URL:

http://YOUR-PC:4000/api/preset/toggle?name=Lower Third - John

Remote control — driving all of this from another location over the internet — is coming as an optional add-on that adds a small always-on relay, so there's no networking setup needed at the venue.

Licensing & watermark

The free version shows a small "StreamGraphics Pro" mark in the corner of the output (control panels are never marked). To remove it, open the License card on the home screen, paste your license key and click Activate. Licenses verify offline, so no internet is needed at your venue, and a key can also unlock optional add-ons.

Updating

When a new version is available you'll see a notice in the app with a link to download it. To update, download the new version and restart the app. Note: refreshing your browser alone won't add new features — the update replaces the app itself. Your saved presets, templates and media stay put.

Keyboard shortcuts (builder)

  • Arrow keys — nudge the selected layer 1px
  • Shift + Arrow — nudge 10px
  • Delete / Backspace — remove the selected layer
  • Alt + click — select the layer beneath the one you clicked
  • Shift / Ctrl + click a Layers row — add to the selection (then Group)
  • Double-click a layer's name — rename it

Troubleshooting

I updated but don't see the new feature

Download the latest version and restart the app. A browser refresh alone won't add new features.

My animation isn't playing on air

Animations play on the output when the graphic goes on/off air. Use Preview animation in the builder to check it instantly. If a graphic is already on air, take it off and back on to replay.

A CSV image isn't showing

Make sure the image is uploaded in the Library's image panel and the image layer has a matching CSV field name. Local paths like C:\…\pic.jpg are fine — the app matches by file name.

The first load in OBS/vMix lags, then it's fine

That's the browser source warming up (loading fonts and images). Add the input and let it sit a few seconds before going live; it's instant afterwards.

Another operator's change appeared

Everyone on the network shares the same live state — that's by design. The last change wins.
