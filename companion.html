The Bitfocus Companion module

Run your whole show from a Stream Deck. The module is free, and it works with the free version of the app too — no licence needed.

Download the module Setup guide

For Bitfocus Companion 3.x · MIT licensed · works with the free and paid versions alike

Buttons that tell you the truth

A key turns red while that graphic is actually on the Program output — not while you last pressed it. Worth a lot when there are twenty buttons in front of you.

Live numbers on the keys

The real score, team names, which game is up, the presenter clock ticking down, the baseball count — printed on the button itself.

It builds its own buttons

Open the Presets tab and drag them out. The module reads your actual show, so five courts gives you five ready-made scoring pages.

It follows your show

Everything is addressed by the name you gave it in the app. Rename a court, add one, or rebuild the show file — your buttons keep working.

Installing it

  1. Download the module using the button above. You'll get a .tgz file — hand it over as it is, don't unzip it first.
  2. In Companion, open the Modules page and use the option to import a module package. Pick the file you just downloaded.
  3. Add a connection and search for StreamGraphics Pro. Fill in two things: the address of the show computer (127.0.0.1 if Companion is on that same machine, otherwise the address the app prints on its home page) and the port, 4000 unless you changed it.
  4. Check it goes green, then open the Presets tab and drag buttons onto your pages. Don't build them by hand — the generated ones already have their feedback and variables wired up.

StreamGraphics Pro has to be running before the connection can go green. If it stays red, check the app is open and that Windows didn't block network access the first time it asked.

Not using Companion?

Everything the module does is also available as plain web addresses — one URL per button. That's the way to drive StreamGraphics from a Stream Deck on its own, or from any other automation. The full list is on the Control API page inside the app, and in the guide.
